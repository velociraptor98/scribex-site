# ScribeX site

The landing page for [ScribeX](https://github.com/velociraptor98/scribex), built
with SvelteKit and prerendered to static files.

```sh
npm install
npm run dev       # http://localhost:5173
npm run build     # static site in build/
npm run check     # svelte-check
```

`build/` is plain HTML, CSS and JS and can be served by any static host.

## Deploying

The site deploys on Netlify. `netlify.toml` sets the build command, the
`build/` publish directory, Node 22, security headers and cache rules, so the
Netlify site needs no settings of its own beyond the linked repository.

The content security policy is generated by SvelteKit (`kit.csp` in
`svelte.config.js`) as a `<meta>` tag that carries the hash of SvelteKit's
inline startup script. It forbids inline styles and any third-party origin:
use classes rather than `style` attributes, and self-host any new asset.

## Shared with the app

- `src/lib/styles/theme.css`: tokens copied from `scribex/src/theme.css`.
- `static/fonts/`: the app's self-hosted Cormorant Garamond and Lora (SIL OFL).
- `static/favicon.svg`, `static/app-icon.svg`: the app's icons.
- `src/lib/commands.ts`: the app's ⌘K matcher, copied verbatim so the demo
  behaves like the product. Re-copy it when the app's version changes.

Links, the download URL and the system requirements are in `src/lib/site.ts`.
